# Quality and assessment limits

## Maintained scope

Read-only Alexa energy reports, the standalone report CLI, optional account linking and their deployment tools.

[CONTRIBUTING.md](../CONTRIBUTING.md) documents checks and review requirements. Tests run with assertions enabled; security failures are not waived to make a badge green. Unit and loopback tests are not physical-device acceptance, a penetration test or proof of every deployment.

## Recorded maintainer statements

The primary maintainer has confirmed familiarity with least privilege, secure defaults, complete mediation and common application/network vulnerabilities and their prevention. The maintainer reports no bug reports, enhancement requests or vulnerability reports outside GitHub in the preceding 12 months. The 16 October 2026 GitHub issue/advisory inventory contained no non-PR reports or advisories for this repository. Pull requests and automated review remain publicly archived.

## Remaining work

No complete accessibility or internationalization audit, complete branch coverage, full-scope 80% statement-coverage measurement, mandatory DCO, independent penetration test or independent two-person maintenance arrangement is claimed. Practical warnings and security analysis run in CI; a maximally strict warning profile and uniform automatic formatting across all languages are not established. Signed release metadata does not by itself prove reproducible builds. Third-party/toolchain limitations must stay visible in any public assessment.

The current public badge record is authoritative for the awarded level. A progress percentage toward Silver is not a Silver award.
